# ToolNest — All-in-One Online Tools Website

A responsive, static website starter containing 36 browser-based tools.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. For best compatibility, run a local static server (for example, VS Code Live Server).

## Included tools

### Image
- Image Compressor
- Image Resizer
- Image Format Converter (JPG / PNG / WebP)
- Grayscale Image
- Rotate Image
- Image to PDF

### PDF
- Merge PDF
- Split PDF (extract page ranges)
- PDF Page Counter / basic PDF details

### Text
- Word Counter
- Case Converter
- Remove Extra Spaces
- Reverse Text
- Find & Replace
- Remove Duplicate Lines
- Sort Text Lines
- Text to Slug
- Lorem Ipsum Generator

### Developer
- JSON Formatter / Minifier
- Base64 Encoder / Decoder
- URL Encoder / Decoder
- HTML Escape / Unescape
- CSV to JSON
- JSON to CSV
- QR Code Generator
- Password Generator
- UUID Generator

### Calculators
- Percentage Calculator
- Discount Calculator
- Age Calculator
- Unit Converter (length, weight, temperature)
- Date Difference
- GST Calculator
- Tip Calculator
- BMI Calculator
- Compound Interest Calculator

## Notes
- File processing is performed locally in the browser for the supported image and PDF tools. The site does not include a file-upload backend.
- PDF and QR features load third-party JavaScript libraries from public CDNs, so an internet connection is required for those features.
- This is a front-end starter, not a production deployment. Before launch, replace the sample brand/contact details, add real Privacy Policy / Terms / About / Contact pages, test on target browsers, configure hosting and domain, and review third-party library licences.
- The BMI calculator is informational only and is not medical advice.
- The example email address uses the reserved `.example` domain and must be replaced.
- No AdSense code is included. Ad placement and approval should be handled after the site has original content and meets the ad network's policies.
